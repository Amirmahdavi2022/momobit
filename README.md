# 🧰 Momobit

ربات جعبه‌ابزار فایل تلگرام — عضویت اجباری کانال، رابط فارسی، روی Render.

## چیکار می‌کند
- 🖼 عکس → PDF
- 🗜 فشرده‌سازی عکس
- 🎵 ویدیو → MP3
- 🎬 فشرده‌سازی ویدیو

## راه‌اندازی روی Render
1. این پوشه را در یک ریپوی گیت‌هاب بگذار.
2. در Render → New → Web Service → همین ریپو، Runtime روی **Docker**.
3. Plan را **Free** بگذار.
4. در Environment این‌ها را ست کن:
   - `BOT_TOKEN` = توکن ربات از BotFather
   - `CHANNEL` = آی‌دی کانال، مثل `@parsv2r`
   - `CHANNEL_LINK` = لینک کانال، مثل `https://t.me/parsv2r`
5. Deploy. Render خودش `PORT` و `RENDER_EXTERNAL_URL` را می‌دهد و ربات وبهوک را ست می‌کند.

## نکته‌ی مهم
ربات باید **ادمین کانال** باشد تا بتواند عضویت کاربران را چک کند.

## محدودیت‌ها
- حداکثر حجم فایل: ۲۰ مگ (محدودیت تلگرام)
- پلن رایگان بعد از ۱۵ دقیقه بی‌کاری می‌خوابد؛ اولین پیام بعدی ~۱ دقیقه دیر جواب می‌گیرد.
