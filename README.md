# 🧰 Momobit

یه ربات تلگرام که فایل‌هاتو برات تبدیل می‌کنه. بدون نصب اپ، بدون سایت پر از تبلیغ.

ربات: [@Momobitbot](https://t.me/Momobitbot)

## چیکار می‌کنه

**عکس**
- تبدیل به PDF
- چند تا عکس با هم توی یه PDF
- کم کردن حجم

**ویدیو**
- در آوردن صدا به صورت MP3
- کم کردن حجم
- ساخت GIF (۶ ثانیه‌ی اول)
- حذف صدا

**صدا و ویس**
- تبدیل به MP3
- تبدیل به ویس تلگرام

## چطور کار می‌کنه

عکس یا ویدیو یا صدا رو می‌فرستی، ربات می‌پرسه باهاش چیکار کنه، دکمه رو می‌زنی. تموم.

برای PDF چند صفحه‌ای هر عکس رو بفرست و «افزودن به آلبوم» رو بزن، آخرش دکمه‌ی ساخت PDF.

## راه‌اندازی

کل کار با Docker انجام می‌شه چون ffmpeg لازم داریم. روی Railway تست شده ولی هر جایی که Docker و یه دامنه‌ی عمومی بده کار می‌کنه.

۱. ریپو رو به سرویس میزبانت وصل کن، Runtime رو Docker بذار

۲. این متغیرها رو ست کن:

| متغیر | چیه |
|---|---|
| `BOT_TOKEN` | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `CHANNEL` | آی‌دی کانالی که عضویتش اجباریه، مثل `@yourchannel` |
| `CHANNEL_LINK` | لینک همون کانال |
| `PUBLIC_URL` | آدرس عمومی سرویس، مثل `https://xxx.up.railway.app` |

روی Railway به جای `PUBLIC_URL` می‌تونی `RENDER_EXTERNAL_URL` بذاری، هر دوش رو می‌خونه.

۳. ربات رو **ادمین کانال** کن. بدون این تلگرام اجازه نمی‌ده عضویت کاربرا چک بشه و قفل عضویت کار نمی‌کنه.

۴. دیپلوی. ربات خودش وبهوک رو ست می‌کنه (اگه تلگرام محدودیت نرخ بده تا ۵ بار دوباره تلاش می‌کنه).

## نکته‌ها

- حداکثر حجم فایل ۲۰ مگابایته، این محدودیت خود تلگرامه نه ربات
- ویدیوی سنگین ممکنه یکی دو دقیقه طول بکشه
- GIF فقط از ۶ ثانیه‌ی اول ساخته می‌شه چون GIF کامل حجمش می‌ترکه و تلگرام قبولش نمی‌کنه
- آلبوم عکس‌ها توی حافظه نگه داشته می‌شه، با ری‌استارت پاک می‌شه

## ساخته شده با

Node 20، [grammY](https://grammy.dev)، ffmpeg. نوشتن PDF دستی انجام شده (JPEG مستقیم embed می‌شه) که وابستگی اضافه نداشته باشه.
